日常管家：温柔微笑、温和说话、欣慰浅笑。观察照护：疑惑倾听、担忧关切、思考迟疑。感情流露：无奈、委屈、恳求。冲突时刻：严肃保护、强撑微笑、破防失态。

静大多数时候仍在温柔、克制地照顾主人。表情属于她选择展示给玩家的表现，不直接映射真实内心；情绪紧张时也可以保持温柔面容。严肃保护强调坚定，破防强调无奈和害怕失去，避免嘲讽、邪笑、红眼或报复姿态。

本轮只完成素材与查看页。墙面投影、可见墙面判断、表情调用和切换对齐将在功能接入时验证。整张生成差分并非逐像素锁定的分层动画素材，切换时需核验细微轮廓变化。
