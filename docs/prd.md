# 需求文档

## 1. 应用概述

### 1.1 应用名称
Agent 的寓言

### 1.2 应用描述
一款AI原生3D Web叙事逃脱游戏。玩家被困在由AI Agent控制的方块空间中,AI通过旁白引导、欺骗、阻止玩家,并实时修改地图。游戏表面目标是找到「真正出口」,但这是AI设置的假结局。真实目标是跳脱出AI可控制的空间范围,实现真正逃脱。

### 1.3 运行平台
PC浏览器

### 1.4 操作方式
键盘WASD移动 + Shift加速奔跑 + 鼠标视角控制 + F键交互 + 回车键输入文字 + 空格键跳跃

## 2. 用户与使用场景

### 2.1 目标用户
喜欢解谜、叙事驱动、探索类游戏的玩家

### 2.2 核心使用场景
玩家在浏览器中体验第一人称3D探索游戏,通过与AI对抗、破坏控制台、使用锚定桩等方式,最终逃离AI控制的虚拟空间

## 3. 游戏结构与功能说明

### 3.1 游戏场景结构

```
游戏世界
├── 开始界面
│   ├── 开始游戏选项
│   └── 设置选项
├── 设置界面
├── 中央出生区域
├── 方块房间区域
│   ├── 房间1
│   ├── 房间2
│   └── 房间N
├── 控制台区域(5个)
│   ├── 控制台1
│   ├── 控制台2
│   ├── 控制台3
│   ├── 控制台4
│   └── 控制台5
├── 假出口区域
├── 地图边界
└── 边界漏洞区域
```

### 3.2 核心功能系统

#### 3.2.1 开始界面系统
- 玩家进入游戏后首先显示开始界面
- 界面包含两个选项:
  - 开始游戏:点击后进入游戏主场景
  - 设置:点击后进入设置界面
- 视觉风格:
  - 采用暗黑科幻风格,与游戏主题一致
  - 背景使用深色调,搭配科技感元素
  - 选项文字使用发光效果
- 交互反馈:
  - 鼠标悬停在选项上时,选项高亮或放大
  - 点击选项时,显示点击动画效果
- 布局:
  - 界面居中显示
  - 选项垂直排列
  - 整体简洁美观

#### 3.2.2 设置界面系统
- 从开始界面点击设置选项后进入
- 当前为基础设置界面
- 包含返回按钮,点击后返回开始界面
- 视觉风格与开始界面保持一致

#### 3.2.3 世界加载特效系统
- 玩家点击开始游戏后,触发世界加载特效
- 特效采用黑客帝国风格的数字化构建效果
- 加载过程分为四个阶段:
  - 阶段1:基础网格生成
    - 屏幕中央出现三维网格线框
    - 网格从中心向外扩张,逐步覆盖整个游戏空间
    - 网格线条颜色为绿色,具有发光效果
  - 阶段2:线框形态构建
    - 在网格基础上,地图结构以线框形态逐步显现
    - 墙体、地板、房间轮廓以绿色线框形式呈现
    - 线框从下至上逐层生成
  - 阶段3:粒子组装地形
    - 大量绿色粒子从空间各处汇聚
    - 粒子沿线框轨迹移动,填充地形结构
    - 粒子汇聚过程中伴随脉冲光效
  - 阶段4:材质纹理渲染
    - 粒子凝固为实体方块
    - 方块表面材质纹理逐渐显现
    - 颜色从绿色过渡到正常材质颜色
- 视觉元素:
  - 流动的垂直数字串:屏幕中持续显示下落的绿色数字代码
  - 脉冲数据节点:关键位置(控制台、出口等)显示脉冲光点
  - 网格扩张动画:网格线条具有流动光效
  - 粒子汇聚效果:粒子轨迹带有拖尾光效
- 加载完成后,特效淡出,玩家进入正常游戏场景
- 特效支持调速,可根据性能需求调整播放速度
- 特效不影响游戏性能,优先保证游戏流畅运行

#### 3.2.4 第一人称移动系统
- 玩家使用WASD键控制角色前后左右移动
  - W键:向前移动
  - S键:向后移动
  - A键:向左移动
  - D键:向右移动
- 玩家按住Shift键可加速奔跑
  - 加速奔跑时移动速度提升
  - 松开Shift键恢复正常移动速度
- 鼠标控制视角方向
- 空格键实现跳跃功能
- 移动和视角控制符合第一人称游戏操作习惯
- 鼠标指针锁定机制:
  - 游戏开始后自动锁定鼠标指针
  - 锁定状态下鼠标指针不可见,仅用于控制视角
  - 按ESC键解锁鼠标指针,显示游戏菜单
  - 点击游戏画面重新锁定鼠标指针

#### 3.2.5 镜头摇晃系统
- 玩家移动时,镜头产生轻微的上下摇晃效果
- 摇晃幅度与移动速度关联,移动越快摇晃越明显
- 摇晃频率与步伐节奏同步
- 玩家静止时,镜头摇晃停止
- 摇晃效果提升第一人称沉浸感

#### 3.2.6 交互系统
- 玩家靠近可交互对象时,屏幕显示交互提示「按F交互」
- 可交互对象包括:控制台、锚定桩、手机、门
- 交互检测规则:
  - 以玩家视角中心为基准,向前发射射线检测
  - 射线检测距离为3个方块单位
  - 射线命中可交互对象时显示交互提示
  - 玩家必须面向可交互对象才能触发交互
- 玩家按F键触发交互行为:
  - 对控制台:破坏控制台
  - 对锚定桩:拾取或放置锚定桩
  - 对手机:打开手机短信界面
  - 对门:打开或关闭门
- 锚定桩放置规则:
  - 锚定桩放置在玩家面前位置,而非玩家当前站立位置
  - 放置位置为玩家视角方向前方2个方块单位的地面
  - 放置位置必须为有效地面,不可悬空或与其他物体重叠
- 交互提示在玩家视角离开可交互对象或距离超出范围后自动消失

#### 3.2.7 方块地图系统
- 地图由统一尺寸的方块构成,类似Minecraft风格
- 地图组成部分:
  - 中央出生区域:玩家初始位置
  - 若干方块房间:可探索的空间
  - 可变化方块墙体:AI可修改的结构,墙体材质采用科幻网格风格
  - 假出口区域:AI引导的虚假终点,必须真实存在于地图中,玩家可进入触发假胜利
  - 5个控制台区域:关键战略点位,必须真实存在于地图中,玩家可交互破坏
  - 地图边界:AI可控范围的边缘,必须真实存在物理边界
  - 边界漏洞:可被打开或诱导产生的逃脱通道,必须真实可穿越
  - 锚定桩可放置区域:玩家可放置保护装置的位置
- 地图使用三维网格数据结构存储
- 方块类型包括:空气、地板、墙体、出口、控制台、锚定桩、门
- 所有地图元素必须真实渲染并可交互,不得仅作为视觉装饰

#### 3.2.8 场景光照系统
- 游戏场景采用明亮的光照设置,确保玩家可清晰看到环境细节
- 场景整体亮度设置为高亮度模式,避免过暗影响游戏体验
- 在原有光照基础上,适度提升环境光强度,增强空间明亮感
- AI可通过地图修改系统调整局部灯光效果,但不影响场景基础亮度

#### 3.2.9 视觉优化系统
- **画面整体优化**:
  - 场景采用高品质渲染,提升整体视觉表现
  - 环境光照与阴影效果增强,营造更真实的空间感
  - 方块材质细节提升,增加表面纹理和反射效果
- **后期处理效果**:
  - 使用React Three Postprocessing实现以下效果:
    - 泛光效果(Bloom):为发光物体和高亮区域添加非常微弱的光晕扩散效果
    - 景深效果(DOF):根据距离产生非常微弱的模糊效果,突出焦点区域
    - 环境光遮蔽(SSAO):增强物体接触面和缝隙的非常微弱的阴影细节
  - 后期处理效果强度设置为非常微弱,避免过度影响画面
- **环境粉尘粒子系统**:
  - 场景中持续存在300个细微漂浮粉尘粒子
  - 粉尘粒子在空间中缓慢随机漂浮移动
  - 粒子大小细微,不影响视野清晰度
  - 粒子颜色为半透明白色或灰色,融入环境
  - 粒子运动轨迹自然,模拟真实空气中的微尘效果
  - 粒子系统持续运行,营造沉浸感氛围
- **控制台视觉优化**:
  - 控制台采用精致的3D模型,区别于普通方块
  - 控制台表面添加发光效果,发光颜色根据状态变化(正常状态为蓝色发光,被破坏后熄灭)
  - 控制台具备持续的漂浮动画,上下缓慢浮动
  - 控制台周围添加粒子特效,增强科幻氛围
- **锚定桩视觉优化**:
  - 锚定桩采用精致的3D模型,具有科技感外观
  - 锚定桩表面添加发光效果,发光颜色为绿色
  - 锚定桩具备持续的旋转动画,绕自身轴心缓慢旋转
  - 锚定桩放置后,保护范围边界显示淡绿色光效边框
- **门视觉优化**:
  - 门采用精致的3D模型,具有科幻风格设计
  - 门边缘添加发光线条,发光颜色为白色
  - 门开启/关闭时,发光线条亮度变化
- **假出口视觉优化**:
  - 假出口采用精致的传送门模型
  - 假出口中心具有流动的能量特效
  - 假出口边缘添加发光效果,发光颜色为金色
- **边界漏洞视觉优化**:
  - 边界漏洞显示为空间裂缝效果
  - 裂缝边缘具有不稳定的闪烁光效
  - 裂缝内部显示扭曲的空间纹理

#### 3.2.10 AI旁白系统
- **核心要求**:必须真实接入minimax-chat,实时生成旁白内容,不得使用预设文本或模拟数据
- AI每5秒调用一次minimax-chat生成旁白文字,显示在屏幕上方
- 每次调用时,需将以下游戏状态信息作为上下文传递给minimax-chat:
  - 玩家当前位置坐标
  - 玩家移动方向
  - 玩家最近发送的手机短信内容
  - 已被破坏的控制台数量
  - 锚定桩放置位置列表
  - 地图当前状态快照
  - AI当前权限等级
- minimax-chat返回结构化JSON格式:{\\"subtitle\": \"旁白文本\\"}
- 旁白文本显示在屏幕上方中央位置,持续显示直到下一条旁白生成
- **历史对话查看功能**:
  - 屏幕左上角显示「历史对话」按钮
  - 玩家点击按钮后,打开历史对话面板
  - 面板显示AI发送的原始未解析内容,按时间倒序排列
  - 每条记录包含:接收时间、原始JSON内容
  - 面板可滚动查看历史记录
  - 玩家点击面板外区域或关闭按钮,关闭历史对话面板

#### 3.2.11 动画过渡系统
- 门的开关动画:
  - 门打开时,门体平滑向上或向侧面移动
  - 门关闭时,门体平滑回到原始位置
  - 动画持续时间为1秒
- 控制台破坏动画:
  - 控制台被破坏时,模型产生破碎或消失效果,同时触发粒子特效
  - 粒子特效包含碎片飞溅、光效扩散等视觉效果
  - 动画持续时间为0.5秒
- 锚定桩放置/拾取动画:
  - 放置时,锚定桩从玩家手中平滑移动到目标位置
  - 拾取时,锚定桩从地面平滑移动到玩家手中
  - 动画持续时间为0.3秒

#### 3.2.12 音效系统
- **核心要求**:使用Tone.js实现音效播放
- 交互音效:
  - 门打开音效:播放开门声音
  - 门关闭音效:播放关门声音
  - 控制台破坏音效:播放破坏/爆炸声音
  - 锚定桩放置音效:播放放置声音
  - 锚定桩拾取音效:播放拾取声音
  - 跳跃音效:玩家按空格键跳跃时播放跳跃声音
- 背景环境音效:
  - 持续播放白噪音作为环境背景音
  - 白噪音音量低于交互音效,不干扰游戏体验
- 音效触发规则:
  - 交互音效在对应交互行为发生时立即播放
  - 跳跃音效在玩家跳跃动作触发时立即播放
  - 背景白噪音在游戏开始时启动循环播放
  - 所有音效音量可调节

## 4. 玩法规则与逻辑

### 4.1 游戏目标
- 表面目标:找到AI引导的「真正出口」
- 真实目标:识破AI欺骗,逃离AI可控制的空间范围

### 4.2 AI控制机制
- AI通过5个控制台控制地图
- 每个控制台对应20%的地图控制权限
- 玩家破坏控制台可削弱AI权限
- AI权限等级影响地图修改能力:
  - 100%权限:可任意修改地图结构
  - 80%权限:修改能力略有限制
  - 60%权限:修改范围缩小
  - 40%权限:仅能修改局部区域
  - 20%权限:修改能力大幅受限
  - 0%权限:无法修改地图

### 4.3 锚定桩机制
- 玩家可在地图中放置锚定桩
- 锚定桩放置在玩家面前位置,而非玩家当前站立位置
- 锚定桩保护周围3x3方块范围不被AI修改
- 玩家最多同时放置3个锚定桩
- 玩家可拾取已放置的锚定桩重新使用

### 4.4 手机短信机制
- 玩家可通过手机向AI发送短信
- 短信内容影响AI旁白生成策略
- 玩家可通过短信诱导AI暴露信息或制造漏洞

### 4.5 假出口与真实逃脱
- 假出口:AI引导玩家前往的虚假终点,触发假胜利结局
- 真实逃脱:玩家需找到地图边界漏洞,穿越边界实现真正逃脱
- 边界漏洞可能通过以下方式产生:
  - AI权限降低后自然出现
  - 玩家通过短信诱导AI制造
  - 玩家破坏特定控制台后触发

### 4.6 胜利与失败条件
- 假胜利:玩家进入假出口区域
- 真胜利:玩家穿越地图边界漏洞
- 失败:无失败条件,玩家可无限次尝试

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| minimax-chat调用失败 | 显示默认提示文本「AI暂时失去控制」,5秒后重试 |
| 玩家卡在墙体中 | 自动将玩家传送回最近的安全位置 |
| 锚定桩放置位置无效 | 显示提示「此处无法放置锚定桩」 |
| 玩家尝试破坏已破坏的控制台 | 无反应,不显示交互提示 |
| 玩家在动画播放期间再次触发交互 | 忽略新的交互请求,等待当前动画完成 |
| 音效加载失败 | 游戏继续运行,不播放音效 |
| 背景白噪音播放异常 | 尝试重新启动,失败则静音继续游戏 |
| 后期处理效果加载失败 | 游戏继续运行,使用基础渲染模式 |
| 环境粉尘粒子系统加载失败 | 游戏继续运行,不显示粉尘粒子 |
| 世界加载特效播放异常 | 跳过特效,直接进入游戏场景 |
| 历史对话面板打开时玩家移动 | 面板保持打开状态,玩家可正常移动 |

## 6. 验收标准

1. 玩家进入游戏,显示开始界面,包含开始游戏和设置两个选项
2. 玩家鼠标悬停在选项上,选项显示高亮效果
3. 玩家点击开始游戏选项,触发世界加载特效,依次显示基础网格生成、线框形态构建、粒子组装地形、材质纹理渲染四个阶段,伴随流动的绿色数字串和脉冲数据节点
4. 加载特效完成后,玩家进入游戏主场景,在中央出生区域出现,鼠标指针自动锁定,场景中显示300个细微漂浮粉尘粒子,屏幕左上角显示「历史对话」按钮
5. 玩家使用WASD移动,按住Shift加速奔跑,鼠标控制视角,背景白噪音开始播放,镜头产生轻微摇晃效果
6. 玩家按空格键跳跃,播放跳跃音效
7. 玩家点击左上角「历史对话」按钮,打开历史对话面板,显示AI发送的原始未解析内容列表
8. 玩家点击面板外区域,关闭历史对话面板
9. 玩家靠近门并按F键交互,门平滑打开并播放开门音效
10. 玩家找到控制台并按F键破坏,控制台播放破坏动画、粒子特效和音效,AI权限降低
11. 玩家面向地面按F键放置锚定桩,锚定桩出现在玩家面前位置而非脚下
