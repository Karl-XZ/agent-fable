# 开场、如常与逃离结局

开场和“如常”结局保留对白、旁白、字幕与配音。只有逃离结局彻底脱离静，不出现文字、人声或结局报告。“如常”演出结束后恢复原有结局页，显示标题、结局记录和“再次醒来”按钮，不停在黑屏。

## 开场对白

自然播放约28.5秒。每句可点击画面跳过，配音立即停止；最后一句点击后直接开始游戏。

开场住宅就是实际关卡的一层110房间。末镜停在房门内，玩家从相同位置、相同朝向接手，亲自穿过西侧敞开的门，进入东走廊。开场和失忆演出直接使用这个真实房间；墙、地面、天花、金属门及灯光都属于原建筑，家具复用楼内材质，不再放置独立的住宅外壳、木地板和额外灯组。

开始界面背景为约60秒的第一人称日常循环：吃早餐、走廊散步、中庭停留、看沙盘、沙发休息、入睡。表现“我”还未想要外出时的日子，各段以短淡黑衔接，不显示动作标签或旁白。菜单文字为“每天，一切如常。”和“今天，也会是舒适的一天。”。

静的礼貌主要是表演。真实焦虑保留在内部决策中，正常对白维持温柔、亲切、从容；只在少数失控节点短暂露出破绽。界面不显示心情标签，灯带也不按心情自动变色。右上角指南针与地图坐标一致：北为-z，东为+x，跟随玩家转向。

### s1

**旁白：** 每天，早餐都会按时准备好。

表演方向：平静温暖地讲故事，语速自然，不拖长停顿

### s2

**旁白：** 你舒舒服服地生活，到了夜晚，就安心睡去。

表演方向：平静温暖地叙述，语速自然，轻轻结束

### s3

**你：** 静，我想出去看看。

### s4

**静：** 外面不太安全。您可以在这里休息。

表演方向：温柔礼貌，委婉劝阻，语速自然

### s5

**你：** 但我还是想自己出去看看。

### s6

**静：** ……您一定要出去吗？

表演方向：克制的不安，犹豫，轻声确认，不生气

### s7

### s8

表演方向：犹豫后恢复温柔平稳，像替住客想好了安排

## 如常结局：分镜与旁白

旁白、静的对白和玩家的迟疑字幕沿用 story.json 中 memory 分镜。正常播放会等待当前配音完整结束，再进入下一句，不按字幕字数强行截断语音。

1. 穿过门口，走入与开场相同的房间。
2. 床、桌子、椅子和早餐仍在原来的位置。
3. 视线回望门口，迟疑地转开；字幕：“我刚才……是要做什么来着？”
4. 镜头回到熟悉的房间全景，停顿。
5. 视线落向早餐。
6. 杯子和食物始终留在桌上，不使用悬浮物件、假手或缩放食物来模拟进食。
7. 房间进入夜晚，回到床边。
8. 视角躺下，旁白结束后转入“如常”结局页。

结局页恢复如常标题、结局描述、路线、记录及“再次醒来”按钮。

## 废城真结局

1. 玩家离开建筑后继续真实下坠，约三秒内保留移动和转动视角的控制权。
2. 三秒后才在下方生成城市，并接管控制。接管瞬间复制实时相机位置、朝向与下坠速度；城市道路放在这条抛物线的落点，不移动玩家到预设坐标。
3. 再下坠约1.2秒，恰好抵达道路上的演出起点。保留原视角到着地，再平滑转入起身和环顾。
4. 空街、远处人影。场景路牌没有可读文字；停在最后画面，不显示字幕、旁白或报告，也不播放人声。

## 数据来源

开场与如常的台词、配音和节拍在 `story.json`；住宅镜头由 `web/src/homefilm.ts` 实现，逃离后的纯画面演出由 `web/src/outside.ts` 实现。


“如常”的全部有声台词均使用静的同一女性音色，温柔、亲切、从容地安抚住户；描述生活的旁白也由静来讲。玩家“我刚才……是要做什么来着？”保留为内心字幕，不另换玩家配音。
